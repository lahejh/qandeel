# Caretakers guide — keeping this app alive

This app is sadaqah jariyah. It must stay free, private and accurate — for as long as Allah wills.
If you are reading this because you are taking over: jazakum Allahu khayran.

## Promises that must never be broken
- Free forever: no ads, no purchases, no subscriptions.
- No data collection, no tracking, no accounts.
- Quran, translations, hadith and azkar are never edited, generated or "improved".
- If the app can't be maintained, transfer it to another nonprofit — do not delete it.

## Where everything is
- Code: this GitHub repo (public, GPL-3.0).
- Plan & rules: `docs/PLAN.md`, `CLAUDE.md`.
- Licenses, design files, audio masters, encrypted keys: Google Drive "Qandeel" folder.
- Passwords & signing keys: password manager (emergency access for named caretakers).
- Store accounts: Google Play Console and Apple App Store Connect (organization account; several admins).

## Every year
Follow `docs/YEARLY-UPDATE.md`.

## Backups that don't depend on the stores
- Web version on GitHub Pages, APK on GitHub Releases, F-Droid listing (Android).
