# levels/ — kids game data

`spot-the-difference/` holds one folder per scene:
- layered vector artwork (no people, faces, animals or birds)
- `scene.json`: change spots, variants (removed/recolored/resized/moved/swapped), difficulty tags,
  locked layers (Quran calligraphy, names of Allah, the Prophet's name — never changed)
- card pool for between-level cards (dhikr, words, hadith with source, masjid facts)

Every spot and variant is reviewed by a person before release.
